# EC Lyrics

Lyrics workspace and stage prompter for the EC community.

## Development

```bash
npm install
npm test
npm run dev
```

To open the Electron shell against the local Firebase emulators, run
`npm run dev` in one terminal and `npm run electron:local` in another.

See [docs/architecture.md](docs/architecture.md) for repository structure,
runtime boundaries, and script-loading rules.
